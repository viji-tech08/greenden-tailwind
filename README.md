# Greenden - Tailwind CSS Project

A responsive plant website created using **HTML and Tailwind CSS**.  
This project was built to practice Tailwind CSS utilities and responsive web design.

## Live Demo

https://viji-tech08.github.io/greenden-tailwind/

## Features

- Responsive navigation bar
- Plant product cards
- Search section
- Mobile responsive design
- Desktop and tablet responsive layout
- Styled completely using Tailwind CSS utility classes
- Responsive layouts using Tailwind breakpoints
- Product images and clean UI sections

## Technologies Used

- HTML5
- Tailwind CSS
- SVG Icons
